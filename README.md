# 창원 LG 선수 경기력 하락 위험 예측 및 컨디션 탐지 모델

## 1. 프로젝트 개요

본 프로젝트는 KBL **창원 LG 세이커스** 선수들의 최근 경기력, 출전 시간, 휴식일, 홈/원정 여부, 상대팀 등의 경기 조건을 활용하여 다음 경기에서 **분당 판타지 포인트(FP_per_MIN)가 하락할 위험**을 예측하는 데이터마이닝 프로젝트입니다.

최근 경기 흐름과 피로도 요인을 함께 반영하여 선수별 경기력 하락 가능성을 사전에 파악하는 것을 목표로 합니다.

## 2. 분석 목적

* 최근 경기력 지표와 피로도 요인이 선수의 경기력 하락과 어떤 관련이 있는지 분석
* 다음 경기에서 `FP_per_MIN`이 하락할 가능성이 높은 선수를 예측
* 선수별 평균 예측 하락 위험도를 산출하여 경기 운영 및 출전 시간 관리에 활용 가능한 인사이트 도출
* 분류 모델의 threshold 조정을 통해 단순 정확도보다 **하락 위험 선수 탐지율(Recall)**을 높이는 방향으로 모델 개선

## 6. Threshold 조정

경기력 하락 위험 선수를 놓치지 않는 것이 중요하다고 판단하여 Random Forest 모델의 예측 확률에 대해 threshold를 조정했습니다.

Validation Set에서 threshold별 성능을 비교한 결과 F1-score 기준 최적 threshold는 **0.40**으로 선택되었습니다.

| 기준             |      값 |
| -------------- | -----: |
| Best Threshold |   0.40 |
| Accuracy       | 0.5769 |
| Precision      | 0.5397 |
| Recall         | 0.9214 |
| F1-score       | 0.6807 |
| ROC-AUC        | 0.6774 |

## 8. 주요 결과 요약

* 전체 데이터에서 FP_per_MIN 하락 비율은 약 **47.85%**로 나타남
* 원정 경기에서 홈 경기보다 하락률이 더 높게 나타남
* 벤치 선수의 하락률이 선발 선수보다 높게 나타남
* 상대팀별로 하락률 차이가 존재하며, Seoul SK전 하락률이 가장 높게 나타남
* 기본 threshold 기준 Random Forest가 가장 안정적인 성능을 보임
* threshold를 0.4로 조정하면 Recall이 크게 향상되어 하락 위험 선수 탐지에 유리함
* 선수별 평균 예측 하락 확률을 통해 양홍석, 윤원상, 허일영 등이 상대적으로 높은 위험도를 보임

## 9. 활용 방안
* 경기 전 선수별 컨디션 리스크 점검

* 벤치 선수 또는 역할 변동이 큰 선수의 경기력 변동성 관리
* 상대팀별 경기력 하락 패턴 파악

* 향후 라인업 최적화, 출전 시간 배분, 선수 로테이션 전략 수립의 기초 자료로 활용

## 11. 결론
