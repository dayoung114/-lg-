# 창원 LG 선수 경기력 하락 위험 예측 및 컨디션 탐지 모델

## 1. 프로젝트 개요

본 프로젝트는 KBL **창원 LG 세이커스** 선수들의 최근 경기력, 출전 시간, 휴식일, 홈/원정 여부, 상대팀 등의 경기 조건을 활용하여 다음 경기에서 **분당 판타지 포인트(FP_per_MIN)가 하락할 위험**을 예측하는 데이터마이닝 프로젝트입니다.

최근 경기 흐름과 피로도 요인을 함께 반영하여 선수별 경기력 하락 가능성을 사전에 파악하는 것을 목표로 합니다.

## 2. 분석 목적

* 최근 경기력 지표와 피로도 요인이 선수의 경기력 하락과 어떤 관련이 있는지 분석
* 다음 경기에서 `FP_per_MIN`이 하락할 가능성이 높은 선수를 예측
* 선수별 평균 예측 하락 위험도를 산출하여 경기 운영 및 출전 시간 관리에 활용 가능한 인사이트 도출
* 분류 모델의 threshold 조정을 통해 단순 정확도보다 **하락 위험 선수 탐지율(Recall)**을 높이는 방향으로 모델 개선

본 프로젝트의 예측 대상은 `target_FP_per_MIN_drop_5`입니다.

| 값   | 의미                         |
| --- | -------------------------- |
| `0` | 경기력 하락 아님                  |
| `1` | FP_per_MIN이 기준 대비 5% 이상 하락 |

전체 데이터의 target 분포는 다음과 같습니다.

Target 비율이 비교적 균형적이므로, 모델 학습 시 심각한 클래스 불균형 문제는 크지 않은 편입니다.

## 8. Threshold 조정

본 프로젝트에서는 경기력 하락 위험 선수를 놓치지 않는 것이 중요하다고 판단하여, Random Forest 모델의 예측 확률에 대해 threshold를 조정했습니다.

Validation Set에서 threshold별 성능을 비교한 결과, F1-score 기준 최적 threshold는 **0.40**으로 선택되었습니다.

### 8.1 Random Forest Threshold 조정 결과

| 기준             |      값 |
| -------------- | -----: |
| Best Threshold |   0.40 |
| Accuracy       | 0.5769 |
| Precision      | 0.5397 |
| Recall         | 0.9214 |
| F1-score       | 0.6807 |
| ROC-AUC        | 0.6774 |

Threshold를 0.4로 낮춘 결과, Accuracy는 일부 감소했지만 Recall이 **92.14%**까지 상승했습니다. 이는 실제 하락 위험이 있는 선수를 더 적극적으로 탐지하는 방향의 모델 운영 방식입니다.

## 13. 한계점 및 개선 방향

### 13.1 한계점

* 데이터가 24-25 시즌과 25-26 시즌 일부에 한정되어 있어 표본 수가 충분히 크지 않음
